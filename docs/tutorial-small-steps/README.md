# Small C++ 한국어 코어 튜토리얼 — 작은 걸음판

기존 38강판과 비교하기 위한 별도 구성입니다. GW-BASIC 교재의 실제 복원본은 아니며, 한 번에 배울 내용을 줄이고 실행 결과를 바로 확인하는 방식으로 새로 구성했습니다.

- 짧은 학습 단위 88개: 개념 하나 → 실행 예제 하나 → 결과 확인 → 연습 하나.
- 1–35: 출력, 계산, 변수, 입력, 조건, 반복, 함수, 문자열, 배열의 작은 단계.
- 36–88: 창과 게임, 알고리즘, 파일, 사용자 타입, 표준 C++ 전환을 목표별로 분리.
- small_main 유지. 런타임이나 IDE 기능 변경 없음. 한국어만 제공.
- 세부 내용을 모두 필수 수업에 넣지 않고 상세 참고서와 교사용 메모에서 찾아볼 수 있게 구성.

## 먼저 읽어 보기

- CONTENTS.md: 전체 순서
- READING.md: 예제·정답을 펼쳐 볼 수 있는 전체 수업 읽기 자료
- TEACHER.md: 설명을 짧게 끊는 방법과 void 등 예상 질문 답변
- REFERENCE.md: 기존 38강의 상세 설명과 코드. 여기의 장 번호는 기존 38강 기준.
- tutorial/: IDE에서 사용할 한국어 튜토리얼 전체 폴더
- validation.json: 검증 결과와 수업별 본문 길이

## IDE에 적용하기

1. IDE를 종료합니다.
2. 기존 tutorial 폴더를 tutorial-backup 같은 이름으로 바꾸어 보관합니다.
3. 이 ZIP의 tutorial 폴더를 그 위치에 넣습니다.
4. IDE를 열어 88개 수업이 보이는지 확인합니다.

**기존 tutorial에 병합하지 마세요.** 이름과 번호가 다른 이전 강의가 남으면 중복됩니다. 원래 구성으로 돌아갈 때도 현재 폴더를 따로 옮긴 뒤 백업 폴더의 이름을 tutorial로 되돌립니다. 다른 확장이나 프로그램 파일은 교체하지 않습니다.

기존 38강 업데이트 ZIP은 그대로 사용할 수 있습니다. 이번 구성의 88은 작은 학습 단위의 수이며, 정규 수업 시간 수를 뜻하지 않습니다. 여러 단위를 묶거나 원하는 만들기 활동에서 멈추어 사용할 수 있습니다.

## 검증 범위

새 도입부의 예제·연습 코드에 대해 컴파일 검사와 실제 콘솔 출력 비교를 수행했습니다. 뒷부분은 이전에 컴파일 검증한 코드와 바이트 단위로 일치하는지 확인했습니다. 모든 수업에서 예제·연습·정답 연결도 확인했습니다.

Qt 창·키보드·마우스·소리의 실제 동작과 IDE 화면 렌더링은 이 환경에서 확인하지 않았습니다. 적용 후에는 첫 출력 예제, 첫 창, 파일 쓰기·읽기 흐름을 직접 확인해 주세요.
