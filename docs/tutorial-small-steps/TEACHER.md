## 한 단위를 마치는 기준

먼저 이번에 무엇을 만들거나 바꿀지 말하고, 예제를 실행합니다. 코드에서 결과를 만든 부분을 짚은 뒤 연습에서 한 곳을 바꿉니다. 아이가 **왜 결과가 달라졌는지 자기 말로 설명할 수 있으면** 다음으로 넘어갑니다. 단어를 모두 외우거나 페이지에 나온 규칙의 예외까지 설명하는 것이 목표는 아닙니다.

88개는 짧은 학습 단위의 수입니다. 매일 한 개씩 해야 한다는 뜻도, 88회의 정규 수업이 필요하다는 뜻도 아닙니다. 여러 개를 함께 진행하거나, 한 예제로 오래 놀아도 됩니다. 이해 속도가 빠르면 자유롭게 합치세요.

본문은 매번 개념 → 실행 예제 하나 → 결과 확인 → 작은 연습 하나의 순서입니다. 코드 틀까지 새로 타이핑하기 부담스럽다면 Try This Code로 열고 필요한 부분만 바꿉니다. 정답은 시도한 뒤 비교하는 자료입니다. 자기소개 같은 열린 문제에는 여러 답이 가능합니다.

## 변수에서 자주 생기는 혼동

`int score = 10;`을 읽을 때는 먼저 **score라는 이름의 공간에 10을 저장한다**는 관계를 잡습니다. int는 정수를 담는 타입이라는 짧은 뜻을 붙입니다. 선언·초기화라는 이름은 소개하되 용어 시험처럼 다루지 않습니다.

`print(score);`와 `print("score");`를 나란히 실행하면 이름과 문자열의 차이를 확인할 수 있습니다. 대입은 기존 상자에 새 값을 넣는 것으로 설명합니다. `score = score + 5;`는 오른쪽 읽기 → 계산 → 왼쪽 저장 순서로 추적합니다.

이름 규칙과 const는 34에서 따로 다룹니다. 그 전에는 예제의 유효한 이름을 사용하면 됩니다. 지역 int나 double을 값 없이 만든 뒤 읽지 않도록, 예제에서는 항상 초기값을 넣습니다.

## 타입과 문자열의 질문

int는 정수, double은 소수 부분이 필요한 수, bool은 참·거짓, char는 문자 값을 담는 타입으로 **필요한 때 각각** 만납니다. 첫 변수 수업에서 이 표 전체를 암기시키지 않습니다.

문자열이라는 데이터 개념은 첫 수업부터 설명합니다. String이라는 타입은 문자열을 변수에 저장할 때 소개합니다. 문자와 char는 문자열에서 하나를 꺼내 볼 때 설명합니다. 문자 하나와 문자열이 화면에 같게 보여도 타입은 다릅니다.

한글 이름을 String에 넣고 출력하는 것은 괜찮습니다. 그러나 length와 []는 바이트를 기준으로 동작합니다. 이 동작을 글자 수와 글자 하나라고 일반화하지 않도록, 위치를 다루는 연습에서는 영문을 씁니다. UTF-8 한글 한 글자를 char 하나에 넣도록 시키지 않습니다.

## 그림 수업은 틀을 반복해서 사용하기

Window의 내부를 처음부터 설명할 필요는 없지만 객체 만들기 → Open → 반복 중 Show → 종료 순서는 짚어 줍니다. String에서 써 본 점 표기를 창에서도 이어 사용합니다. show는 그림뿐 아니라 창의 입력 처리에도 필요합니다.

기존 코드처럼 한 문장짜리 if나 while에 중괄호가 생략된 경우가 있습니다. 그림 수업의 첫 도형 예제에서 이를 설명합니다. 아이가 문장을 추가할 때는 중괄호를 넣어 함께 묶도록 도와주세요.

게임 두 수업은 긴 코드를 처음부터 새로 외우는 시간이 아닙니다. 완성된 프로그램을 실행하고 입력·갱신·충돌·그리기의 위치를 찾은 뒤 한 부분씩 바꾸는 조립 활동입니다. 상세한 물리 충돌이나 게임 엔진 설계는 이번 범위가 아닙니다.

## 심화는 필요에 맞춰 선택하기
