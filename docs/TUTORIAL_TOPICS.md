# Topic-based tutorial

The active curriculum contains 40 core topics and two Image extension topics in Korean and English. It consolidates the previous 100 core and three Image lessons without changing the executable examples, exercises, images or data files.

Each topic contains short teaching sections, one primary exercise, and additional optional practice. The IDE and website initially collapse additional exercises. Complexity and challenge topics are optional. Students can stop within a topic and continue later.

The IDE displays topic titles rather than a numbered task list. Old lesson identifiers resolve through `tutorial/aliases.json`. The last viewed lesson migrates to its containing topic; an old topic is marked read only if all of its original lessons were read. The consolidated curriculum stores progress under curriculumV3, preserving curriculumV2 records.

Website redirects in `tutorial/redirects.json` preserve old lesson URLs. Fresh builds replace copied lesson directories so obsolete folders cannot create duplicate lessons.
