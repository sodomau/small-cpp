# English tutorial

All 97 core lessons and three Image extension lessons have English text,
including explanations, exercise prompts and hints. Examples, starters and
solutions are shared with Korean so both editions run the same programs.

Choose **Settings → Tutorial Language → English** in a build containing this
content pack. Korean remains the default, and the preference is saved.

## Translation checks

Run `tools/verify_english_tutorial.py` to require explicit English files for
every lesson, no remaining Korean text, identical runnable directives, and
unchanged example/output fences. The Qt tutorial regression loads both
languages, compares shared solutions and tests unavailable-language fallback.
