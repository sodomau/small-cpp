# Curriculum v3 notes

- Lessons 1–30 use ordinary value parameters consistently, including `String` and `Array`.
- Lesson 31 is **References — Sharing Without Copying**.
- Lesson 31 introduces the memory/value model explicitly: value copy -> mutable reference -> const reference.
- From Lesson 31 onward, larger read-only inputs may use idiomatic `const T&`.
- Numeric output formatting is intentionally not added until a lesson creates a concrete need for it.
