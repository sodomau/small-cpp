# Program Examples

These examples are intentionally different from `examples/reference`.

Reference examples answer: **How do I use this API?**

Program examples answer: **What can I make with Small C++?**

- `ascii_art.cpp` — nested loops and console drawing
- `number_guessing.cpp` — input, conditions, loops, sound
- `drawing_pad.cpp` — mouse interaction and persistent drawing
- `bouncing_ball.cpp` — animation, elapsed time, collision, sound
- `reaction_timer.cpp` — Timer callback + StopWatch
- `pong.cpp` — a small real-time game combining graphics, keyboard, timing and sound
- `save_game.cpp` — binary persistence using native C++ int/double representation

These examples are not API-coverage tests. They should stay readable and motivating.
