## What you will learn

A **return value** is a value sent back to the caller. return sends the value back and ends that function's execution.

## Try it

@code example.cpp

The int at the beginning means the result is an integer. The program stores the 16 returned by Square(4) in result. The function handles calculation; SmallMain handles output.

InputInt was also a function that returns a value: the integer it read.

Expected output:

```text
16
```
