# Small C++

Small C++ is a small, beginner-friendly environment for learning real
C++.

## Start

Run `SmallCppIDE.exe`, then open **Learn → Tutorial...**. The included core tutorial contains 97 lessons in Korean and English. Choose **Settings → Tutorial Language
→ English** to switch languages. Settings lists the
languages supplied by the installed content pack.

## Documentation

See the `docs` folder:

-   `GETTING_STARTED.md`
-   `SMALL_CPP_GUIDE.md`
-   `API.md`
-   `DESIGN.md`
-   `TUTORIAL_ENGLISH.md`
-   `NAMING_CONVENTIONS.md` — API naming and migration from older programs

No separate compiler or Qt installation is required for the portable
package.

## Why “Small C++”?

The developer, Sunghyun Cho, first discovered programming through **GW-BASIC** as a child and wanted to bring some of that same immediacy to learning C++. The name **Small C++** is a nod to **Small Basic**; Small C++ is not based on Small Basic and is not a new language or simplified C++ dialect.

**The immediacy of BASIC. The path to C++.**
